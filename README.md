# 🍽️ SAVORLY

### ✨ Discover • Cook • Savor ✨

> **Your next delicious meal is just a click away.**

Savorly is a modern and responsive recipe discovery platform designed to help users discover delicious recipes, explore cuisines, find cooking inspiration, and enjoy a smooth food discovery experience.

## 🌟 Features

- 🍳 Recipe Discovery
- 🥗 Food Categories
- 🥪 Appetizers
- 🍛 Main Courses
- 🍰 Desserts
- 🔎 Recipe Search
- 🤖 Smart Recommendations
- ❤️ Favorite Recipes
- 🛒 Shopping List
- 👨‍🍳 Cooking Mode
- ⏱️ Cooking Timer
- 🥗 Dietary Preferences
- 🌍 Cuisine Explorer
- 📱 Responsive Design
- ⚡ Fast & Smooth UI
